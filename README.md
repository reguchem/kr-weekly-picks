# 주간 3종목 추천 · 성과 추적 (kr-weekly-picks)

매주 **화요일 장마감 직후** KOSPI·KOSDAQ 시가총액 상위 300종목에서 3종목을 추천합니다.
보유 종목은 **매일** 하락 위험 신호를 점검하고, 추천대로 매매했을 때의 수익률(1주·1개월·3개월·누적, KOSPI 대비)을
GitHub Pages로 보여줍니다. 매매는 사용자가 직접 하며, 이 시스템은 정보만 제공합니다.

## 동작 방식

| 언제 (KST) | 무엇을 |
|---|---|
| 화요일 15:33 | 이번 주 3종목 추천 (당일 종가 기준) + Claude 시장 브리핑 + 텔레그램 알림 |
| 평일 매일 15:33 | 보유 종목 점검(매도 경고), 추천별 수익률·포트폴리오 곡선 갱신 |
| 분기 1회 / 수동 | 2015년~현재 백테스트: 전략 7개 × 요일 5개 비교 |

- **추천가 = 화요일 종가.** 같은 가격으로 사려면 한국투자증권 앱에서 15:30~16:00 **시간외 종가** 주문을 쓰면 됩니다.
  16:00 이후 KRX 애프터마켓(~20:00)은 실시간 가격이라 종가와 다를 수 있습니다.
- 화요일이 휴장이면 그 주의 다음 거래일에 추천합니다.
- GitHub Actions의 예약 실행은 몇 분~수십 분 늦을 수 있습니다. 실행은 15:33에 예약되어 있고, 종가 데이터가 올라올 때까지 최대 12분 기다립니다.

## 추천 로직: 테마·수급 전략 (기본값)

한국 시장은 업종·테마 단위로 자금이 몰렸다 빠지는 순환이 강해서, 종목보다 **업종을 먼저** 봅니다.

1. **업종 강도.** 업종별로 소속 종목의 1개월·3개월 수익률 순위 중앙값(75%)과 외국인 순매수 강도(25%)를 합칩니다.
   여기에 **Claude 뉴스·정세 전망(+1/0/−1)을 ±0.15만큼 보정**합니다.
2. **후보 업종.** 강도 상위 3개 업종에서만 신규 편입합니다. 5위 안에 있으면 보유를 유지합니다.
3. **종목 점수.** 업종 강도 35%, 52주 고가 근접 25%, 거래대금 증가(20일/120일) 15%, 외국인·기관 20일 순매수 25%.
4. **제외 조건.** 20일선 아래, 1개월에 40% 넘게 오른 종목, 20일선보다 25% 넘게 위에 있는 종목(과열).
5. **수수료를 고려한 교체 (시드 100만원 기준).**
   - 백테스트 선택구간(2015~2021)에서 **점수 순위 구간별 다음 1주 평균 수익률**을 측정합니다(1~3위, 4~10위 …).
     표본 잡음을 줄이려고 전체 평균 쪽으로 50% 당긴 값을 "예상 1주 수익률"로 씁니다.
   - 빈자리는 예상수익이 가장 높은 종목으로 채웁니다. 보유 종목은 **(새 종목 − 보유 종목) 예상수익 × 4주 > 왕복 거래비용(약 0.37%)**일 때만 바꿉니다.
   - 전략 조건에서 탈락한 보유 종목(20일선 이탈, 업종 5위 밖, 과열)은 교체합니다.
   - **주가 ≤ 종목당 금액의 50%**(시드 100만원이면 약 16만원)인 종목만 신규 후보로 둡니다. 1주 단위라 남는 현금을 줄이기 위해서입니다.
   - 성과는 **정수 주식·원 단위**로 계산합니다. 페이지에 종목별 수량, 평가금액, 현금이 표시됩니다.

### 시장 브리핑 (Claude API, 선택)

화요일마다 Claude가 웹 검색으로 최근 1~2주의 **외국인 수급, 국내 경제(금리·환율·수출·정책), 세계 정세(미국 금리, 반도체 사이클,
중국, 지정학)**를 정리하고 업종별 전망을 냅니다. 브리핑은 페이지에 표시되고, 업종 전망은 위 1번 보정에만 쓰입니다.
과거의 뉴스 판단은 재현할 수 없어서 백테스트에는 들어가지 않습니다. 대신 실제 기록이 쌓이면 효과를 추적할 수 있습니다.
예상 비용은 월 수 달러(Sonnet 기준)입니다.

### 매일 보유 종목 점검 (매도 경고)

| 신호 | 기준 |
|---|---|
| 20일선 이탈 | 종가 < 20일 이동평균 |
| 고점 대비 하락 | 편입 후 최고가 대비 -10% 이하 (-15% 이하면 곧바로 '경고') |
| 외국인 이탈 | 5일 연속 순매도, 또는 20일 순매도가 거래대금의 5% 초과 |
| 업종 약화 | 업종 강도 5위 밖으로 하락 |
| 뉴스 악재 | Claude 점검 결과 (실적 쇼크, 유상증자·CB, 규제, 대주주 매도 등). 심각하면 곧바로 '경고' |

신호가 1개면 **주의**, 2개 이상이면 **경고**입니다. 새로 생기거나 심해진 경고만 텔레그램으로 알립니다.
매도 여부는 사용자가 판단합니다. 전략의 정기 교체는 화요일에만 합니다.

## 설치 (약 15분)

1. GitHub에서 새 저장소를 만듭니다. Pages를 무료로 쓰려면 Public이어야 합니다.
2. 이 폴더의 파일을 모두 올립니다. `.github` 폴더도 꼭 포함하세요.
3. **Settings → Actions → General → Workflow permissions**를 **Read and write**로 바꿉니다.
4. **Settings → Pages**: Deploy from a branch, **main**, **/docs**.
5. **Settings → Secrets and variables → Actions**에서 아래 항목을 등록합니다(선택이지만 권장).
   - Secrets `ANTHROPIC_API_KEY`: console.anthropic.com에서 발급. 없으면 브리핑·뉴스 점검 없이 정량 로직만 동작합니다.
   - Secrets `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`: 텔레그램 @BotFather로 봇을 만들고 내 채팅 ID를 확인해 넣습니다.
   - Variables `PAGE_URL`: 페이지 주소. 알림에 링크로 들어갑니다.
   - Variables `ANTHROPIC_MODEL`(선택): 기본값은 `claude-sonnet-5-5`입니다.
6. **Actions → backtest → Run workflow**를 실행합니다. 첫 실행은 10년치 시세·수급·PER/PBR 수집으로 30~120분 걸립니다.
7. **Actions → weekly → Run workflow**를 `force`에 체크해서 실행하면 첫 추천이 생성됩니다.
8. `https://<아이디>.github.io/<저장소>/`에 접속합니다.

## 설정 (`src/config.py`, `src/strategy.py`)

- `SEED = 1_000_000`(시드), `MAX_PRICE_FRACTION = 0.5`, `HOLD_WEEKS_EST = 4`
- `TRADE_WEEKDAY = 1`(화), `N_PICKS = 3`, `UNIVERSE_SIZE = 300`
- `FEE`: 한국투자증권 실제 수수료로 수정하세요(기본 0.015%, 뱅키스 비대면 계좌는 더 낮을 수 있음). 증권거래세(`SELL_TAX`)는 세법이 바뀌면 수정하세요.
- `DEFAULT_STRATEGY = "theme_flow"`, `STRATEGY_MODE = "fixed"`. `"auto"`로 바꾸면 백테스트 선택구간 1위 전략을 자동으로 사용합니다.
- `TOP_SECTORS`, `KEEP_SECTORS`, 버퍼 순위(`STRATEGIES`의 마지막 값)

## 데이터 출처와 한계

- 시세·종목·업종 분류는 네이버 금융, 외국인·기관 순매수는 pykrx(KRX)이고 실패하면 네이버를 씁니다. PER/PBR은 pykrx입니다.
  KRX 정책 때문에 수집이 실패하면 해당 요소를 빼고 동작하며, 페이지에 그 사실이 표시됩니다.
- 백테스트는 **현재** 시총 상위 종목과 **현재** 업종 분류를 쓰기 때문에 생존편향과 분류 편향이 있습니다.
- 추천별 수익률은 비용 제외, 포트폴리오 곡선은 비용 포함입니다.
- 모든 내용은 참고 정보이며 투자 권유가 아닙니다.

## 로컬 테스트 (네트워크·API 없이)

```bash
pip install -r requirements.txt
SYNTHETIC=1 python -m src.backtest
SYNTHETIC=1 python -m tests.simulate_history 16
cd docs && python -m http.server   # http://localhost:8000
```
가상 데이터로 테스트한 뒤에는 `docs/data/*.json`과 `data/cache/*`를 지우고 커밋하세요.
